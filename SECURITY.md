# Security and sensitive findings

This research preview is documentation, not a production client or security audit.
It has no wallet connection, signing, transaction submission, or hosted service.

No private vulnerability reporting channel has been verified for this project at
launch. Do not put secrets, identifying wallet records, or actionable unpublished
exploit details in public Issues or pull requests. Keep sensitive material local
until a suitable private channel is verified and disclosure is authorized.

Public Issues may be used for non-sensitive documentation or policy errors.
A future private disclosure channel will be listed here only after it is actually
available. No email address, response-time promise, or bug bounty is implied.

If a secret is exposed, stop further publication and notify its owner through an
already trusted private channel. Removal from a branch is not proof that public
copies or Git history no longer contain it. Any credential or history remediation
requires appropriate authorization.
