# Papertrade Mechanics Lab

**看懂 Papertrade：从交易意图到最终结算。**

一个独立的开源研究项目，从用户观察和来源分析开始，后续逐步引入 REA
（Reverse Engineer Anything）辅助调查与可复现模型，解释 Papertrade 可观察的机制。

## 我们正在研究的问题

- 为什么 BTC 有时可以开空，却不能开多？
- 开仓和平仓在哪里等待？它与盈利赔付等待有什么区别？
- 页面显示的盈利如何变成余额变化或待赔付债权？
- 为什么用户报告的单位亏损所获 PAPER 数量会随时间变化？
- 杠杆、保证金及平仓数量限制分别来自界面、中继服务还是合约？
